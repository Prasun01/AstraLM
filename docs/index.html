Explain how on-device quantized inference achieves low latency on ARM architectures.
A
Quantized on-device inference executes directly on ARM NEON and GPU/NPU vector registers using 4-bit and 8-bit integer matrix multiplications (Q4_K_M, Q8_0). By compressing weight matrices from 16-bit floating point down to 4-bit integers, memory bandwidth requirements are reduced by up to 75%, allowing memory-bound mobile processors to stream tokens at 20–45 tokens per second with zero external server roundtrips.
