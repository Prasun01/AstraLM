? FAQ

Frequently asked questions.

01What is AstraLM? +
AstraLM is an open-source hybrid AI assistant for Android. It operates as a local-first engine using native C++ inference (llama.cpp / LiteRT) to run GGUF models 100% offline, while also offering a secure, zero-telemetry BYOK (Bring Your Own Key) Cloud Mode for frontier models like Claude 3.5, GPT-4o, DeepSeek, and Gemini.
02Which local and online models are supported? +
Local Offline: DeepSeek-R1 Distill Qwen (1.5B), Qwen 2.5 Coder (1.5B/3B), Google Gemma 2 (2B), SmolLM2 (1.7B), and any custom GGUF file.

Online Cloud (BYOK): Anthropic Claude 3.5 Sonnet / Haiku, OpenAI GPT-4o / o3-mini, Google Gemini 2.0 Flash / Pro, DeepSeek V3 / R1 Cloud, Groq (Llama 3.3 70B @ 300+ TPS), Together AI, OpenRouter, and self-hosted Ollama / vLLM servers.
03What are the hardware requirements? +
Any Android 8.0+ device with a 64-bit ARM processor (ARMv8 / ARM64). We recommend 6GB+ RAM for 1.5B-2B models and 8GB+ RAM for 3B models.
04Does AstraLM collect any data? +
Zero. AstraLM has zero telemetry, zero trackers, and zero analytics. All chat history, models, and tokens stay strictly in your local device storage.
05Is AstraLM free and open source? +
Yes! AstraLM is 100% free and open-source under the MIT license. You can inspect the code, build from source, or download the pre-built signed APK from GitHub.
